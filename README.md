## 🌟 نظرة عامة
**TellmeAppS** هو مشروع تطبيقي للمحادثات والتواصل الاجتماعي، يعتمد على بنية برمجية منظمة تضمن فصل المكونات (Separation of Concerns) لسهولة التوسع والتطوير المستقبلي، ويوفر واجهة استخدام مرنة مع دعم الاتصال الفوري لتحديث الرسائل والإشعارات.

---

## ✨ الميزات الرئيسية
- 💬 **محادثات فورية:** تبادل الرسائل في الوقت الفعلي.
- 👤 **إدارة الحسابات:** إنشاء حساب جديد، تسجيل الدخول، وتخصيص الملف الشخصي.
- 📱 **تصميم متجاوب:** يعمل بشكل ممتاز على كافة الشاشات (الهواتف، الأجهزة اللوحية، وأجهزة الكمبيوتر).
- 🔐 **أمان البيانات:** حماية بيانات المستخدمين وإدارة الجلسات بشكل آمن.

---

## 📂 هيكلة المشروع وشرح الملفات

تم تنظيم الملفات والمجلدات وفق أفضل الممارسات البرمجية لتسهيل الصيانة والتطوير:

```text
TellmeAppS/
├── public/                  # الملفات الثابتة (Frontend Assets)
│   ├── index.html           # واجهة المستخدم الرئيسية
│   ├── css/
│   │   └── style.css        # تنسيقات الواجهة وتنسيق التجاوب
│   └── js/
│       ├── main.js          # المنطق البرمجي للواجهة والتفاعل (DOM)
│       └── chat.js          # منطق إرسال واستقبال الرسائل الفورية
├── src/                     # الشفرة المصدرية للباك إند (Backend Logic)
│   ├── config/
│   │   └── db.js            # إعدادات الاتصال بقاعدة البيانات
│   ├── controllers/         # معالجة طلبات المستخدمين والتفاعل مع قاعدة البيانات
│   │   ├── authController.js# معالجة المصادقة وتسجيل الدخول
│   │   └── chatController.js# معالجة الرسائل واسترجاع السجل
│   ├── models/              # تعريف هيكل البيانات (Data Models / Schemas)
│   │   ├── User.js          # هيكل بيانات المستخدم
│   │   └── Message.js       # هيكل بيانات الرسالة
│   └── routes/              # مسارات الـ API (Endpoints)
│       ├── authRoutes.js    # مسارات تسجيل الدخول والتسجيل
│       └── chatRoutes.js    # مسارات غرف المحادثة والرسائل
├── .env.example             # قالب لمتغيرات البيئة السرية
├── .gitignore               # الملفات المستبعدة من رفعها إلى GitHub
├── package.json             # ملف التوصيف وإدارة المكتبات للمشروع
├── server.js                # نقطة البداية للمشروع وتدشين الخادم
└── README.md                # الدليل التعريفي الشامل للمشروع
